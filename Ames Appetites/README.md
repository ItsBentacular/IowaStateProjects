# Ames Appetites

This is a project I worked on second semester as a sophomore at ISU in my User Interface design class, made by Dillon Conrad and I. Made using Javascript, React Framework, and MongoDB to store data, it is a fully functioning restaurant searching website for the city of Ames, Iowa.
